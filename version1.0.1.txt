PiliPlus BTR Turbo — version 1.0.1
发布日期：2026-10-16
应用版本：1.0.1（Android versionCode：2）
基于：PiliPlus 2.1.6.2 / PiliPlus BTR 1.0.0

相对 1.0.0 的修改

1. 正式版与测试版区分
   正式版采用真正的 Release 构建，应用名为 PiliPlus BTR Turbo。
   后续 Debug 测试版统一命名为 BTR Debugger。
   两者包名和签名独立，可同时安装，账号及设置各自保存。
   Debug 版保留原调试签名，能够覆盖此前的调试包。
   关闭界面右上角的 Debug 横幅。

2. 加载速度显示
   视频加载图标下方改为显示当前下载速度，不再显示缓存时间点。
   每 500 毫秒刷新，按速度显示 KB/s 或 MB/s。
   BTR 开启时使用音视频上游接收字节的合计速率，包含重试及慢块补救流量，
   本地缓存读取不计作网络下载；其他网络播放读取播放器 cache-speed。

3. 横屏 BTR 设置
   设置弹窗的标题与内容支持整体上下滑动。
   底部“取消”和“应用”按钮固定显示，缩小弹窗上下留白。
   解决横屏高度不足时无法完整查看设置的问题。

4. 实机诊断与构建
   Release 版保留每两秒一次的 BTR 下载、并发、缓冲及重试状态日志。
   新增 tool/watch-android-logs.ps1，支持按应用 UID 采集两版应用日志，
   应用进程重启后可继续采集，日志保存在配置的本地日志目录。
   构建脚本支持 debug/release，并检查正式版签名配置。
   补齐本地回环网络配置的 includeSubdomains 属性，满足 Release 校验。
